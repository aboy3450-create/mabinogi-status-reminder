# 新瑪奇狀態提醒器

Windows 版《新瑪奇》狀態、技能冷卻、破防與 G27 王機制提醒工具。

目前公開版本：**v13.58**

## 下載

不需要自行編譯，請到 [Releases](../../releases/latest) 下載最新的 `mabinogi-status-reminder-v13.58-win-x64.zip`，解壓縮後執行 `新瑪奇狀態提醒器.exe`。

## 使用需求

- Windows 10／11 x64
- 已安裝 [Npcap](https://npcap.com/)
- 啟動時允許系統管理員權限

程式會直接透過 Npcap 讀取遊戲封包並在畫面中央顯示提醒。第一次監聽後，既有狀態通常需要在遊戲中重新套用一次才會被偵測。

## v13.58 重點

- 將 G27 珠子封包偵測整合到主程式，不必另外開啟偵測器。
- 主畫面的「怪物」分類改名為「副本」，新增 `[G27]珠子數偵測`。
- 中央會原地刷新珠子數，例如 `5` 或 `5+4`。
- 按住 End 時，只有本輪已偵測到珠子才會顯示數量；Page Down 可一併清除。
- 保留原珠子分配網頁的本機自動同步功能。
- 破防的「上到／覆蓋／延長」中央訊息最多保留最近兩項。
- 同一技能仍由最新施放者原地刷新；第三個不同技能會立即擠掉最舊項目。
- 破防倒數、消失、自動缺漏、完整提示及事件紀錄不受影響。
- 精簡二王口水及三、四王起飛／退後的介面說明，不再顯示內部封包代碼或待確認分類。
- 偵測判定與實際提醒內容維持不變。
- 事件紀錄 Beta 移到「儲存目前」所在操作區下方。
- 說明與提醒規則移到事件紀錄下方。
- 雙槍射擊及轉換領域的逐秒倒數會原地刷新，不再累積成一長串。
- 保留 G27 王機制、破防唯一目標、隊友 Debuff 合併與其他既有提醒。

完整內容請參考 [CHANGELOG.md](CHANGELOG.md)。
