# 新瑪奇狀態提醒器

Windows 版《新瑪奇》狀態、技能冷卻、破防與 G27 王機制提醒工具。

目前公開版本：**v13.59**

## 下載

不需要自行編譯，請到 [Releases](../../releases/latest) 下載最新的 `mabinogi-status-reminder-v13.59-win-x64.zip`，解壓縮後執行 `新瑪奇狀態提醒器.exe`。

## 使用需求

- Windows 10／11 x64
- 已安裝 [Npcap](https://npcap.com/)
- 啟動時允許系統管理員權限

程式會直接透過 Npcap 讀取遊戲封包並在畫面中央顯示提醒。第一次監聽後，既有狀態通常需要在遊戲中重新套用一次才會被偵測。

## v13.59 重點

- 修正關閉破防「技能顯示」後，仍可能出現上到／覆蓋／延長訊息。
- 新增預設勾選的「隱藏占星扣防技能」；倒吊人與倒數提醒不受影響。
- 破防施加提示可選最多顯示 1 或 2 項，預設為 1。
- 槍手之眼與觸媒反應對敵提示只保留最新一筆；倒數及消失仍完整保留。
- 戰場的 10 秒／5 秒提醒會在同一位置原地刷新。
- G27 三、四王起飛已確認；退後偵測維持不變。
- 一王礦石暫時強制灰化、刪除線並停用，等待日後修正。
- 移除只會在結算骰珠時反應的 G27 珠子數偵測。
- 事件紀錄 Beta 移到「儲存目前」所在操作區下方。
- 說明與提醒規則移到事件紀錄下方。
- 雙槍射擊及轉換領域的逐秒倒數會原地刷新，不再累積成一長串。
- 保留 G27 王機制、破防唯一目標、隊友 Debuff 合併與其他既有提醒。

完整內容請參考 [CHANGELOG.md](CHANGELOG.md)。
